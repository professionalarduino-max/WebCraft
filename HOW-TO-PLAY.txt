WebCraft - Minecraft in your browser (fan remake)
=================================================

WHAT THIS IS
------------
A complete game: singleplayer with saves + your own multiplayer server.
The server needs nothing but Node.js - zero dependencies.


QUICK START (Windows / Mac / Linux)
-----------------------------------
1. Install Node.js LTS from https://nodejs.org (click "LTS", then Next-Next).
2. Unpack this archive into any folder.
3. Open a terminal (command prompt) in that folder:
   - Windows: Shift + right click on the folder -> "Open in Terminal"
     (or: File Explorer -> type cmd in the address bar -> Enter)
   - Mac/Linux: right click -> "Open in Terminal"
4. Run:

     node server/mp-server.js --port 8080 --name "My Server"

5. Open in your browser:  http://localhost:8080
6. Click "Singleplayer" (your own world) or "Multiplayer" (the server world).

Stop the server: Ctrl+C in the terminal.

Useful flags:
  --port 8080        listen port
  --name "My Server" server name shown in chat and in the server card
  --seed 12345       world seed (same world for everyone)
  --op Nickname      give operator rights (comma-separated for several)
  --db world.json    use a different world file (default server/db.json)
  --max-deltas N     how many block edits to keep (default 20000)

Tip: the very first player to join a server with no operators becomes one.


SINGLEPLAYER vs MULTIPLAYER
---------------------------
- Singleplayer: the world is stored in your browser (localStorage), only you see it.
- Multiplayer: one shared world, saved on the server in server/db.json.
  Everyone who joins builds together. Blocks, thrown items, time, weather,
  mobs damaged by players and player positions are all synced.

Connect from the menu: press the Multiplayer button, type a nickname and the
server address (for the server above it is ws://localhost:8080/ws - and if you
opened the game from that server, the address is filled in automatically).


HOW TO INVITE A FRIEND (3 ways)
-------------------------------
Way 1 - Cloudflare Tunnel, free, 2 minutes (your friend just opens a link):
  1. Download cloudflared:
     https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
  2. With the server running, in a SEPARATE terminal:

       cloudflared tunnel --url http://localhost:8080

  3. The output shows a link like https://something.trycloudflare.com - send it.
  4. Your friend opens the link -> Multiplayer -> plays with you.
  Downside: the link changes every time you restart the tunnel.

Way 2 - free hosting (permanent link, 24/7):
  Render.com / Railway.app / Fly.io all have a free tier.
  Upload the whole folder and set the start command to:

     node server/mp-server.js --port $PORT --name "My Server"

  (the host fills the port in through $PORT).
  You get a permanent address like https://webcraft-xxxx.onrender.com.
  Note: free tiers sleep when nobody plays and wake up in ~30 seconds.

Way 3 - one Wi-Fi network:
  Find your local IP (Windows: ipconfig / Mac/Linux: ip addr) and have your
  friend open http://YOUR_IP:8080 -> Multiplayer.

YOUR OWN DOMAIN (CNAME)
-----------------------
The repository ships a CNAME file containing:

    professionalarduino-max.webcraft.dev

That tells GitHub Pages "serve this site on that hostname". For it to actually
work, WHOEVER CONTROLS webcraft.dev must add a DNS record:

    Type: CNAME   Name: professionalarduino-max   Value: professionalarduino-max.github.io

If you do not control webcraft.dev the address will not resolve, and GitHub keeps
the site reachable on https://professionalarduino-max.github.io/WebCraft/ - in
that case just delete the CNAME file.

Note: a page served over https cannot connect to a plain ws:// server (the
browser blocks mixed content). If the game itself is opened from an https page,
the multiplayer server must also be behind https/wss - put it behind a reverse
proxy (Nginx/Caddy) with a TLS certificate.


CONTROLS
--------
  WASD          walk, Space - jump, mouse - look
  Left click    mine / hit, Right click - place / use
  E             inventory and 2x2 crafting
  1-9 / wheel   select hotbar slot
  Shift         sneak, double-tap Space - fly (creative)
  T /           chat and commands
  Tab           player list (multiplayer): name, health, ping, dimension
  F3            debug overlay (includes connection status, ping, queued edits)
  F / F5        change camera (1st / 3rd person)
  Esc           pause / release the mouse


MULTIPLAYER COMMANDS
--------------------
  /list or /players   who is online (dimension, ping, operator mark)
  /ping               your latency to the server
  /tell <name> <text> private message (/msg, /w, /whisper also work)
  /me <action>        emote, e.g. /me waves
  /tp <player>        teleport to a player
  /spawn              teleport back to spawn
  /kick <player>      (operator) disconnect a player
  /op <player>        (operator) grant operator rights

Connection health:
  - If the server or your Wi-Fi blinks, the game reconnects automatically and
    keeps playing offline; the chat shows "reconnecting".
  - Blocks you place while offline are queued and pushed when the link is back,
    so nothing is lost.
  - The server console prints every join/leave/chat and also serves /status
    (JSON with players, ping, seed, edit count) and /players.


IF THE SCREEN IS BLACK / BUTTONS DO NOT WORK
--------------------------------------------
Press Ctrl+F5 (hard reload - clears cached scripts).
Still broken? Press F12, open the Console tab and copy the red error.


REDSTONE? YES!
--------------
Levers, buttons, pressure plates, dust, torches, repeaters, comparators,
observers, pistons, dispensers, hoppers, lamps, target blocks, TNT,
note blocks, daylight sensors. Recipes are the same as in Minecraft.
