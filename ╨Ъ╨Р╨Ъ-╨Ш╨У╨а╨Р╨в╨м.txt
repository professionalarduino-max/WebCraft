WebCraft — Майнкрафт в браузере (фанатский ремейк)
=====================================================

ЧТО ЭТО
------
Полная игра: одиночный режим с сохранениями + свой мультиплеер-сервер.
Серверу не нужно ничего, кроме Node.js — зависимостей ноль.

БЫСТРЫЙ СТАРТ (Windows / Mac / Linux)
--------------------------------------
1. Установи Node.js LTS с https://nodejs.org (кнопка "LTS", дальше "Далее-Далее").
2. Распакуй этот архив в любую папку.
3. Открой терминал (командную строку) в этой папке:
   - Windows: Shift + правая кнопка по папке → "Открыть в терминале"
     (или проводник → в адресной строке набери cmd и Enter)
   - Mac/Linux: правая кнопка → "Открыть в терминале"
4. Выполни команду:

     node server/mp-server.js --port 8080 --name "Мой сервер"

5. Открой в браузере:  http://localhost:8080
6. Нажми "Одиночная" (свой мир) или "Сетевая" (общий мир сервера).

Остановить сервер: Ctrl+C в терминале.

ОДИНОЧНАЯ vs СЕТЕВАЯ
--------------------
- Одиночная: мир хранится в твоём браузере (localStorage), виден только тебе.
- Сетевая: общий мир сервера, постройки хранятся в server/db.json.
  Все, кто зашёл на сервер, строят вместе.

КАК ПОЗВАТЬ ДРУГА (3 способа)
------------------------------
Способ 1 — Cloudflare Tunnel, бесплатно, за 2 минуты (друг открывает ссылку):
  1. Скачай cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
  2. Пока сервер запущен, выполни в ОТДЕЛЬНОМ терминале:

       cloudflared tunnel --url http://localhost:8080

  3. В выводе появится ссылка вида https://что-то.trycloudflare.com — скинь её другу.
  4. Друг открывает ссылку → "Сетевая" → играет с тобой.
  Минус: ссылка меняется при каждом перезапуске туннеля.

Способ 2 — бесплатный хостинг (постоянная ссылка, 24/7):
  Render.com / Railway.app / Fly.io — у всех есть бесплатный тариф.
  Залей туда эту папку целиком, команда запуска:

     node server/mp-server.js --port $PORT --name "Мой сервер"

  (порт хостинг подставит сам через переменную $PORT).
  Получишь постоянный адрес вида https://webcraft-xxxx.onrender.com.
  Нюанс бесплатных тарифов: сервер "засыпает" без игроков и просыпается ~30 сек.

Способ 3 — одна Wi-Fi сеть:
  Узнай свой локальный IP (Windows: ipconfig / Mac/Linux: ip addr),
  друг в той же сети открывает http://ТВОЙ_IP:8080 → "Сетевая".

УПРАВЛЕНИЕ
----------
  WASD — ходить, пробел — прыгать, мышь — смотреть
  ЛКМ — ломать/бить, ПКМ — ставить/использовать
  E — инвентарь и крафт, 1–9 — выбор блока
  Shift — красться, двойной пробел — полёт (в креативе)

ЕСЛИ ЧЁРНЫЙ ЭКРАН / КНОПКИ НЕ РАБОТАЮТ
---------------------------------------
Нажми Ctrl+F5 (жёсткая перезагрузка, сбрасывает кэш скриптов).
Не помогло — нажми F12, вкладка Console, скопируй красную ошибку.
